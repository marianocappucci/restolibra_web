Integraciones

Conectá Restolibra con MercadoPago para cobrar con QR, con ARCA/AFIP para facturación electrónica, y con tu servidor de correo para enviar comprobantes por email.

Todas las integraciones se configuran desde Configuración → Integraciones. Cada sección tiene un botón Probar conexión que verifica que los datos sean correctos.

MercadoPago

La integración con MercadoPago tiene dos usos principales: cobrar con QR dinámico en mesas, barra, takeaway o delivery, y recibir pagos de links de cobro que aparecen en la Bandeja de pagos para facturarlos desde ahí.

Credenciales necesarias

CampoDónde obtenerlo
Access Token Panel de desarrolladores MP → tu app → Credenciales de producción. Empieza con APP_USR-.
User ID Tu perfil de MercadoPago → abajo de tu nombre aparece el ID numérico. También visible en el panel de desarrolladores.
POS ID (External ID) En Tu negocio → Puntos de venta, creá un PDV y definí su External ID (ej: MOSTRADOR). Solo necesario para cobros QR presenciales.
Webhook Secret En la app de desarrolladores → Webhooks, registrá la URL y copiá la firma secreta que MP genera. Recomendado para mayor seguridad.

Cómo obtener el Access Token paso a paso

  1. Ingresá a mercadopago.com.ar/developers/panel/app.
  2. Creá una nueva aplicación (o seleccioná una existente).
  3. Andá a la pestaña Credenciales de producción.
  4. Copiá el Access token que empieza con APP_USR-.

Cómo obtener el User ID

  1. Iniciá sesión en mercadopago.com.ar.
  2. Hacé clic en tu avatar (arriba a la derecha) → Tu perfil.
  3. El User ID es el número que aparece debajo de tu nombre.

Cómo crear el POS ID (para cobros presenciales)

  1. En el panel de MercadoPago, andá a Tu negocio → Puntos de venta.
  2. Creá una sucursal si no tenés una.
  3. Dentro de la sucursal, creá un Punto de venta de tipo PDV.
  4. En el campo External ID escribí un código propio (ej: MOSTRADOR). Ese es el valor que va en Restolibra.

Configurar el Webhook

El webhook permite que MercadoPago avise automáticamente a Restolibra cuando entra un pago. La URL se genera automáticamente en Configuración → Integraciones → MercadoPago — solo tenés que copiarla con el botón.

  1. En el panel de desarrolladores, entrá a tu aplicación y luego a Webhooks.
  2. Copiá la URL que muestra Restolibra en Configuración y pegala en el campo URL de MP.
  3. Seleccioná el evento Pagos (payment).
  4. Copiá la firma secreta que MercadoPago genera y pegala en el campo Webhook Secret en Restolibra.

Tip: el Webhook Secret es opcional pero muy recomendado. Cuando está configurado, el sistema verifica la firma criptográfica de cada notificación y rechaza las falsas.

Importante: usá siempre las credenciales de producción, no las de prueba, para procesar cobros reales.

Probar la conexión

Una vez guardadas las credenciales, hacé clic en Probar conexión. El sistema consulta la API de MercadoPago y muestra tu nickname, User ID, email y país de la cuenta. Si ves un error, verificá que el Access Token sea el de producción y que esté completo.

Bandeja de pagos MercadoPago

Todos los pagos que entran a tu cuenta de MercadoPago (por links de cobro o transferencias) se muestran en Integraciones → Pagos MercadoPago. Desde ahí podés generar facturas, dar de alta clientes y ver el historial.

El número de pagos pendientes aparece como un badge rojo en el menú lateral para que no se te pase ninguno.

Pagos vía webhook

Cuando alguien te paga por un link de cobro u otro método digital de MP, el pago aparece automáticamente en la sección Pagos pendientes de factura. Para cada pago podés:

  • Generar factura — abre un diálogo donde podés editar el concepto antes de emitir. Si hay ARCA configurado, se obtiene el CAE automáticamente. Si hay email configurado, la factura se envía al cliente.
  • Ignorar — marca el pago como ignorado y lo mueve al historial.
  • Dar de alta el cliente — si el pagador no está registrado en Clientes, podés darlo de alta con sus datos pre-llenados desde el pago.

Transferencias bancarias y de billeteras

Las transferencias que entran desde bancos (CBU) o billeteras externas (CVU) no llegan por webhook — hay que traerlas manualmente con el botón Sincronizar.

  1. En la sección Transferencias recibidas, elegí el rango de días (últimos 7, 15, 30 o 60 días).
  2. Hacé clic en Sincronizar. El sistema consulta tu cuenta MP y trae las transferencias nuevas.
  3. Para cada transferencia podés ver el nombre del emisor, banco de origen y CBU.
  4. Como el sistema bancario no provee el email del emisor, podés cargarlo manualmente con el botón Cargar email y así poder enviar la factura.
  5. Una vez cargado el email, podés dar de alta el emisor como cliente o directamente generar la factura.

Tip: si la transferencia es de alguien que ya tenés registrado como cliente, no hace falta cargar el email — podés generar la factura igual (sin envío por email).

Generar una factura desde la bandeja

  1. Hacé clic en el botón Factura del pago o transferencia pendiente.
  2. En el diálogo que se abre, podés modificar el Concepto de la factura.
  3. Confirmá con Generar factura.
  4. El sistema crea la factura, obtiene el CAE de ARCA (si está configurado), genera el PDF y lo envía por email al cliente.
  5. El pago pasa al historial con estado Facturado y un link a la factura.

ARCA / Facturación electrónica

Para emitir facturas electrónicas necesitás un certificado digital emitido por AFIP. El proceso implica generar una clave privada, obtener el certificado desde el portal ARCA y subirlo al sistema.

Paso 1 — Generar la clave privada y el CSR

Herramienta: necesitás OpenSSL instalado. En Linux/Mac ya viene incluido. En Windows podés usar Git Bash o WSL.

  1. Abrí una terminal y ejecutá:
    openssl genrsa -out clave_privada.key 2048
  2. Luego generá el CSR (pedido de certificado):
    openssl req -new -key clave_privada.key -subj "/C=AR/O=Mi Restaurante/CN=CUIT 20123456789" -out mi_restaurante.csr
    Reemplazá CUIT 20123456789 con tu CUIT sin guiones.
  3. Guardá bien el archivo clave_privada.key — es uno de los dos archivos que subís a Restolibra.

Paso 2 — Obtener el certificado desde ARCA

  1. Ingresá con CUIT y Clave Fiscal (nivel 3 o superior) a auth.afip.gob.ar.
  2. Buscá el servicio Administración de Certificados Digitales.
  3. Hacé clic en Nueva solicitud de certificado.
  4. Pegá el contenido del archivo mi_restaurante.csr generado antes.
  5. Descargá el certificado resultante (.crt o .pem).

Paso 3 — Configurar el punto de venta

  1. En el portal ARCA, buscá el servicio ABM de Puntos de Venta.
  2. Creá un punto de venta de tipo Facturación electrónica — Web Services.
  3. El número asignado es el que ingresás en el campo Punto de venta en Restolibra.

Paso 4 — Subir los archivos a Restolibra

  1. Andá a Configuración → Integraciones → ARCA.
  2. Completá el CUIT, punto de venta y seleccioná el ambiente.
  3. Subí el archivo clave_privada.key en el campo Clave privada.
  4. Subí el archivo certificado.crt en el campo Certificado.
  5. Guardá y usá el botón Probar conexión para verificar.

Tip: usá el ambiente Homologación para hacer pruebas sin emitir comprobantes reales. Cambiá a Producción cuando todo funcione correctamente.

Seguridad: la clave privada no se comparte con nadie ni se sube a servicios externos. Solo la subís una vez a este servidor, que es de uso exclusivo tuyo.

Email / SMTP

Configurá el servidor de correo para enviar facturas y presupuestos por email desde el sistema, con el PDF adjunto automáticamente.

Configuración para Gmail

Importante: Gmail no permite usar tu contraseña normal para enviar email desde apps externas. Necesitás generar una contraseña de aplicación de 16 caracteres.

  1. Activá la Verificación en dos pasos en tu cuenta de Google (es un requisito de Google para usar contraseñas de aplicación).
  2. Ingresá a myaccount.google.com/apppasswords.
  3. En el campo Nombre de la app escribí Restolibra y hacé clic en Crear.
  4. Google te mostrará una contraseña de 16 caracteres — copiala en ese momento (no se vuelve a mostrar).
  5. En Restolibra, andá a Configuración → Integraciones → Email y completá:
    Servidor: smtp.gmail.com · Puerto: 587 · Usuario: tu email completo · Contraseña: los 16 caracteres copiados.
  6. Guardá y usá Probar conexión para verificar.

Probar la conexión

El botón Probar conexión abre una conexión SMTP real con tu servidor y verifica las credenciales. Si la prueba falla con un error de autenticación, revisá que la contraseña sea la contraseña de aplicación (no la normal) y que el usuario sea tu email completo.
