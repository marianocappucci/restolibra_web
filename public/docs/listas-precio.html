Listas de Precios

Creá múltiples listas de precios para distintos canales — salón, delivery, eventos — y aplicalas directamente al vender.

Para qué sirve

El módulo de Listas de Precios te permite manejar precios diferenciados por canal o segmento sin necesidad de modificar el precio base de cada producto. Podés tener, por ejemplo:

  • Una lista Salón con el precio de venta estándar
  • Una lista Delivery con un recargo para compensar comisiones de plataformas
  • Una lista Eventos basada en el precio de costo más un margen distinto

Al crear una venta o pedido, elegís qué lista aplicar y los precios de los productos se autocompletan desde esa lista.

Crear una lista de precios

  1. Andá a Inventario → Listas de precios → Nueva lista.
  2. Ingresá el nombre de la lista (por ejemplo, "Delivery") y una descripción opcional.
  3. Elegí la fuente inicial de precios:
    • Vacía — se crea sin precios precargados; los cargás manualmente.
    • Precio de venta del producto — importa el precio base de cada producto.
    • Precio de costo del producto — importa el costo registrado (o calculado por receta).
    • Otra lista existente — copia los precios de una lista ya creada.
  4. Guardá la lista. El sistema la crea y te lleva al detalle donde podés editar los precios individuales.

Editar precios en la lista

En el detalle de la lista aparece una tabla con todos los productos activos. Para cada producto se muestra el precio actual de la lista y el margen % respecto al costo.

  • Hacé clic en el precio de cualquier producto para editarlo directamente en la celda.
  • Usá el filtro por categoría para trabajar con un grupo de productos a la vez.
  • Cuando termines, presioná Guardar cambios para confirmar todas las modificaciones.

Atención: si intentás salir de la página con precios modificados sin guardar, el sistema te avisa para que no pierdas los cambios.

Actualización en lote por porcentaje

El botón Actualizar en lote permite ajustar precios de varios productos a la vez sin editar uno por uno. Parámetros disponibles:

ParámetroDescripción
BasePrecio sobre el que se aplica el ajuste: precio actual de la lista, precio de venta del producto, o precio de costo
PorcentajeValor positivo para aumento, negativo para descuento (por ejemplo, 10 = +10%, -5 = −5%)
CategoríaOpcional. Si se elige una categoría, el ajuste aplica solo a esos productos

Antes de confirmar, el sistema muestra una vista previa con el precio nuevo de cada producto afectado. Podés revisar y luego aceptar o cancelar.

Tip: usá la actualización en lote cuando tus proveedores aumentan costos de insumos. Seleccioná "Precio de costo" como base y aplicá el porcentaje de aumento para mantener tus márgenes.

Usar la lista en un pedido o venta

  1. Al abrir una mesa o crear un pedido, si hay listas activas en el sistema aparece un selector Lista de precios.
  2. Elegí la lista deseada.
  3. Al agregar productos, el buscador devuelve automáticamente los precios de esa lista en lugar del precio base del producto.

Tip: si un producto no tiene precio definido en la lista seleccionada, el sistema usa el precio de venta base del producto como respaldo.

Activar o desactivar una lista

Cada lista puede marcarse como activa o inactiva desde su configuración. Las listas inactivas no aparecen en el selector. Esto es útil para archivar listas de temporadas o promociones anteriores sin eliminarlas.
