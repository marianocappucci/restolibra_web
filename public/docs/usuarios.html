Usuarios y permisos

Administrá quiénes pueden acceder al sistema y qué pueden hacer. Restolibra tiene tres roles: administrador, operador y mozo.

Roles del sistema

RolQué puede hacer
Administrador Acceso total: configuración, usuarios, módulos, reportes, backup y restore, logs del sistema.
Operador Acceso operativo: ventas, caja, productos, clientes, salón. No puede modificar configuración ni ver logs.
Mozo Acceso acotado únicamente al salón: mapa de mesas y pedidos de barra/takeaway/delivery. No ve el dashboard, la caja ni ningún otro módulo administrativo — ni siquiera escribiendo la URL directamente.

Recomendación: Usá el rol Mozo para el personal de salón que solo necesita tomar comandas desde el celular. Usá Operador para quien también maneja caja y facturación. Reservá Administrador para el dueño o encargado general.

El rol Mozo, pensado para el celular

Un usuario con rol Mozo, al iniciar sesión, cae directo en el mapa de mesas — nunca ve el dashboard. Desde el sidebar solo tiene disponibles Mesas y Pedidos; el resto de las secciones (Dashboard, Caja, Facturación, Reportes, Configuración, KDS, etc.) están ocultas, y si de todas formas intenta entrar por URL directa a cualquiera de ellas, el sistema lo redirige de vuelta al salón.

Además, el flujo de salón se puede instalar como una app desde el navegador del celular ("Agregar a pantalla de inicio"), para que el mozo lo abra como cualquier otra aplicación. Ver el detalle en Salón y Mesas.

Crear un usuario nuevo

  1. Andá a Administración → Usuarios en el menú lateral.
  2. Hacé clic en Nuevo usuario.
  3. Completá el nombre, nombre de usuario (login), contraseña y rol.
  4. Guardá. El usuario ya puede ingresar con esas credenciales.

Cambiar contraseña

Un administrador puede cambiar la contraseña de cualquier usuario desde Administración → Usuarios.

Desactivar un usuario

Para que un usuario ya no pueda ingresar, podés desactivarlo en lugar de eliminarlo. Así se conserva el historial de sus operaciones (pedidos tomados, cierres de caja, etc.).

  1. Andá a Administración → Usuarios.
  2. Buscá el usuario y hacé clic en Editar.
  3. Desmarcá Activo y guardá.

Atención: No elimines usuarios que tienen ventas o movimientos de caja registrados, ya que se perdería la trazabilidad de esas operaciones.

Auditoría y logs

El sistema registra las acciones importantes de cada usuario (login, ventas, cambios de configuración). Los administradores pueden revisar estos logs en Administración → Logs.
